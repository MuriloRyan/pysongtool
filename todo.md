## Project Context
`pysongtool` is a Python package for music theory tools, including chord, scale, interval, and progression analysis. It is modular, extensible, and already published on PyPI for easy installation. The project aims to provide both programmatic and CLI access to music theory utilities, with a focus on usability, correctness, and community contribution.
